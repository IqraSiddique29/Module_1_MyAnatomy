# 📊 Module 1: Data Analysis, Statistics & Probability

## 🌟 Overview
This notebook contains hands-on Python exercises covering Exploratory Data Analysis (EDA), descriptive statistics, outlier detection, data visualization, and probability.

## 📚 Topics Covered

### 🦠 1. COVID-19 Exploratory Data Analysis (EDA)
- 📥 Downloading a dataset using KaggleHub
- 🔍 Exploring data using Pandas
- 🧹 Checking missing values and duplicate records
- 🔄 Data type conversion and feature engineering
- 🏥 State-wise COVID-19 case analysis
- 📈 Calculating recovery and death rates
- 📊 Visualizing confirmed cases and deaths
- 📅 Analyzing COVID-19 cases over time

### 📐 2. Descriptive Statistics
- ➗ Mean, median, and mode
- 📏 Range, variance, and standard deviation
- 📊 Percentiles and quartiles
- 📦 Interquartile Range (IQR)
- 🚨 Detecting outliers using the IQR method
- 📝 Summary statistics using `describe()`

### 📉 3. Data Visualization
- 📊 Histograms
- 📦 Box plots
- 📊 Bar charts
- 📈 Line charts
- 🎨 Visualizations using Matplotlib and Seaborn

### 🎲 4. Probability
- 🪙 Simulating coin tosses using NumPy
- 🔢 Counting heads and tails
- 🧮 Calculating experimental probability
- 🛒 Calculating customer purchase probability
- 🎯 Conditional probability of purchase given that an item was added to the cart
